税号‌通常指‌纳税人识别号‌，是办理涉税事项的唯一代码标识 。
EMQX 是一款开源的分布式 MQTT 消息服务器 和物联网数据流平台。它专为物联网（IoT）设计，能连接数百万个设备，安全地处理和传输实时数据。[高性能：单机和集群能支持海量设备同时在线。协议支持：支持 MQTT 5.0、3.1.1、3.1，以及 CoAP 等其他物联网协议。分布式：采用集群架构，方便水平扩展。数据集成：能轻松把数据传到数据库或 AI 分析平台]
质量戳是工业自动化（如 OPC、SCADA 系统）中标识‌数据有效性状态‌的代码标签，非实体印章；其核心含义为：‌192=好（有效），0/其他=坏（无效/通讯故障）‌。‌‌
PCB板（Printed Circuit Board），即印制电路板，是电子元器件的支撑体和电气连接的载体。因几乎所有电子设备都需使用，它被称为“电子产品之母”。
PCBA（成品板）：将各种电子元器件（如芯片、电阻、电容）通过表面贴装（SMT）或插件（DIP）焊接在PCB上，形成特定功能的完整电路板。
CNC加工（Computer Numerical Control计算机数字控制），是一种数字制造技术。是一种精密的减材制造技术。通过预编程的计算机软件控制机床，直接从实心原材料中精准去除多余部分以成型部件。它具备加工精度极高、重复性强、材质适用广的特点，广泛应用于航空航天、汽车及医疗器械等领域。
车削加工：工件高速旋转，由固定的刀具进行切削，最适合加工圆柱形或圆锥形零件。
铣削加工：工件固定，由计算机控制旋转的切削刀具在多个轴向上移动，逐层削去材料以创造复杂的三维形状。
工艺定额是制造业在正常生产条件下，生产单位合格产品所消耗的原材料数量和工时的标准。它是企业编制生产作业计划、控制生产成本、核算经济指标以及下发领料单和工票的核心依据。
准结时间是指为生产不同产品进行产线切换时，完成准备和结束工作所消耗的时间。它是生产工序时间定额的重要组成部分。【准备时间： 生产开始前的各项筹备工作。例如：领取物料和工艺文件、安装和调试夹具与模具、预热设备、输入程序代码以及进行首件检验等。终结时间： 生产结束后的收尾工作。例如：拆卸和清理夹具、归还工具图纸、清理工位等。】
MRP 最常指物料需求计划（Material Requirements Planning）。它是一套生产与库存管理系统，通过计算得出“需要什么、需要多少、何时需要”，帮助制造企业在正确的时间以正确的数量准备物料，避免停工和库存积压。
外协车间并非企业自有生产部门，而是指‌承接外部委托加工任务的外部工厂或独立生产单元‌，其本质是“外部协作”模式下的物理执行场所 。‌‌

启发式排程是一种利用经验法则和直觉来安排工作顺序的方法。它的目标是在合理时间内找到一个“足够好”的方案，而不是耗费大量时间去计算最完美的方案。这就像整理行李：你不必尝试所有可能的组合，只要优先放大件物品就能快速搞定。

常见的启发式排程规则：

*   **最早交期优先 (EDD)：** 谁的交货时间最早，谁就先做。
*   **最短处理时间优先 (SPT)：** 耗时最少的任务先做。
*   **最少剩余工序优先 (MOP)：** 剩下的步骤最多的任务先做。
*   **关键路径优先：** 对整个项目进度影响最大的任务先做。

仓库物料中的“图号”是指工程设计图纸的编号。它是制造型企业中，研发、生产与仓储部门用来精准识别某个具体零部件的标识。通过图号，仓库和车间人员可以追溯到该物料在图纸上的具体规格、形状和加工工艺。

QMS（质量管理系统Quality Management System）是企业用于数字化管理质量流程和数据的专业系统，核心功能包括设计质量分析（如FMEA）、来料检验、过程控制（如SPC）、不合格品处理及持续改进等。

稼动率是衡量设备在计划生产时间内实际投入生产的比例，计算公式为：稼动率=实际运转时间÷计划生产时间×100%。它反映设备因故障、等待或换线等非计划停机导致的利用率损失。需要注意的是，高稼动率并不等同于高效率，若生产过剩库存或不良品，反而会降低实际效益。精益管理强调按需生产，结合节拍时间和OEE（综合设备效率）等指标，实现稳定、高品质的生产。&#x20;

IQC (Incoming Quality Control)：即来料质量控制。负责对采购的原材料、零部件进行检验，防止不合格物料进入生产环节。这是质量控制的“第一道防线”，通过抽检确保物料符合规格要求，从源头减少质量成本。

IPQC (In-Process Quality Control)：即制程质量控制。指产品从物料投产到最终包装过程中的品质控制。常在工序间巡回检查（也称巡检），核心是预防不合格品产生并防止其流入下道工序，确保生产过程稳定受控。&#x20;

OQC (Outgoing Quality Control)：即出货质量控制。在成品出厂前进行系统性检验。这是产品交付前的最后一道质量关卡，确保出货产品满足客户品质要求，达成“零缺陷”出货的目标。&#x20;

设备点检是按照标准周期对设备指定部位进行检查的管理方法，旨在早期发现故障隐患并及时处理，确保设备正常运行。 点检保养是设备管理的核心环节，分为日常点检、定期点检和精密点检三类。日常点检由操作人员每日通过"五感"（看、听、摸、闻、触）检查设备异音、温度、润滑等，确保当日正常运行；定期点检由专业人员每月停机检测设备性能；精密点检则由技术人员不定期用专业仪器排查疑难问题。&#x20;

SOP（标准作业程序Standard Operating Procedure）： 负责“做”。规定了工人如何一步步组装或加工产品（如：先拧哪颗螺丝、用多大力度）。

SIP（标准检验程序Standard Inspection Procedure）： 负责“查”。规定了检验的方法、步骤、频率和合格标准（如：用游标卡尺测长度、抽检数量、正负公差要求）。

SIP 在 MES 系统中的具体应用，1.电子化指导： 在工人完成一道工序后，MES 系统会将对应的 SIP推送到质检员的平板或电脑屏幕上。2.防呆防错： 系统会明确提示检验要求。如果产品不符合 SIP 设定的标准，系统会拦截，防止不良品流入下一道工序。3.数据记录： 质检员按照 SIP 测量后，将数据（如具体尺寸）录入系统，MES 会自动生成质量报表。

在注塑行业中，“吨位500”是指注塑机的最大锁模力（Clamping Force）为500吨。这是衡量注塑机加工能力和规格的最核心指标，决定了这台机器能生产多大尺寸、多重的塑料制品。

什么是锁模力？在注塑过程中，高压的融化塑料会被注入到模具中。这种高压会产生一股强大的力量，试图把模具撑开。【锁模力的作用：就是注塑机从两侧施加的“夹紧力”，防止模具被塑料高压冲开。】【500吨的意思：这台注塑机在闭合模具时，最大能产生相当于 500吨重物压下来 的锁模力量，确保生产时产品不会漏胶、不长毛边（飞边）。】【注塑机按吨位通常分为微型、小型、中型和大型：500吨属于：中大型注塑机。】

“标准班产960”通常指一个标准工作班次内，生产某件产品或完成某项工作的计划数量是960件（或960个单位）。

“低转产损耗”是指在工厂更换产品生产线时，减少浪费的材料、时间和机器停工数量。例如，从生产大号手机壳换成小号手机壳时，通过快速换模技术，让机器短暂停机就能继续生产。这能大幅降低成本并提升效率。

在产线军师语境下，UNS 更适合理解为 统一语义空间（Unified Namespace / Unified Semantic Space）。

上下文工程（给模型看什么）、提示词工程（让模型怎么做、怎么说）、工具调用机制（模型实际能调用的能力）。上下文决定“输入材料”，提示词“行为规则”，工具层决定“真实能力”。

产线军师的长期定位不是单一功能系统，而是面向 Agent 时代的工业智能操作平台。建立在企业现有 CMS / LMES / MES / 设备数据源 之上，而不是替代现有执行系统，让工厂中的关键对象、状态和业务上下文进入统一语义体系，让分析、诊断、协同和业务动作具备统一的能力开放方式，让不同角色的智能体围绕生产、质量、设备、交付和管理目标协同工作。

UNS 建立统一语义空间 把订单、产线、设备、工序、报警、质量、人员、项目等对象放到一致的业务语境中

MCP 建立能力开放层 把查询、分析、诊断、协同与业务动作封装为 AI 可调用能力

Agent 建立业务编排与闭环层 根据上下文选择能力、组合知识、组织结论并推动后续动作

LMES（Line Manufacturing Execution System，产线级制造执行系统）是基于 AI 技术驱动的产线 MES 工具平台，构建于成熟稳定的盛云圈 CMS 平台之上。CMS是针对装备数字化业务场景诞生的 AI 驱动的新一代工业 SCADA（数据采集与监视控制系统）管控一体开放平台。LMES 专注于提供"过程可控、全程可溯、自主可控"的产线级制造执行解决方案。

LMES：专注于生产流（Production Flow）本身的执行、控制与优化，LMES 作为智能制造的核心执行引擎，通过融合 AI、数据分析等先进技术，保障生产过程的高效率与高质量，推动制造企业实现从自动化到智能化的跨越。

InfluxDB 是由 InfluxData 公司开发的一款开源、高性能的‌时序数据库（Time Series Database, TSDB）‌，专为处理带有时间戳的海量数据而设计。它在 DB-Engines 时序数据库排行榜中长期位居第一，广泛应用于物联网（IoT）、系统监控、实时分析等领域 。‌

HMI (Human Machine Interface)：操作与控制的桥梁，HMI是人与机器之间进行信息交换的媒介，主要供现场操作员使用，用于下达指令、监控设备状态和处理异常。

看板 (Dashboard / Electronic Kanban)：可视化与决策支持，看板通常指大屏显示系统或电子看板，主要供管理人员、巡检员或参观者使用，旨在快速呈现关键绩效指标（KPI）和生产进度。

HMI（人机界面）与‌看板（Dashboard/Andon）‌是现代工业自动化与智能制造中两个紧密相关但侧重点不同的概念。HMI侧重于“操作与控制”，而看板侧重于“监控与展示”。

‌OEE 设备综合效率（OEE，Overall Equipment Effectiveness）是衡量制造流程或设备效能的核心指标，由可用率、性能率和质量合格率三个关键因素构成 \[1-2]，在工业4.0背景下，云、边缘计算、物联网等技术提供实时数据帮助衡量和改进OEE \[1]。其计算公式为OEE=可用率×性能率×质量合格率，百分比结果反映设备运行的整体有效性，基准如Elite为85%-90%，受六种大损失影响，包括设备故障、设置调整、空转、速度降低、过程缺陷和良率损失 \[4]。

SPC统计过程控制（Statistical Process Control，简称SPC）是基于数理统计方法的质量管理技术，通过分析生产过程识别系统性异常因素，利用控制图监控过程稳定性，采用流程能力指数（如Cp、Cpk）评估质量水平。

MES生产执行系统（Manufacturing Execution System，MES），是连接企业计划层（如ERP）与车间控制层的关键软件系统。它通过实时采集生产数据、管理生产订单、调度资源、控制质量与追溯产品，实现对制造过程的精细化管控。MES系统能有效提升生产效率、保障产品质量、实现全流程追溯，并支持柔性制造，是制造业数字化转型的核心环节，广泛应用于汽车、电子、半导体、医药、食品饮料等离散与流程制造行业。

APS高级计划系统（Advanced Planning System，APS）是基于供应链管理与约束理论的企业管理运营系统，通过数学模型与智能优化算法整合企业内外部资源约束，生成涵盖战略、战术及操作层面的供应链计划，并为客户提供精确交货承诺。

MOM制造运营管理‌（Manufacturing Operation Management）：用于整合企业人员、设备、物料等资源，管理生产过程，适用于汽车制造、电子制造、半导体制造等行业 。‌

PDU（Protocol Data Unit，协议数据单元）是一个基本概念，它指的是在网络中传输的数据的基本单位。PDU可以是任何类型的网络数据包，例如在网络层（如IP包）和传输层（如TCP段或UDP报文）中。

假设你正在通过HTTP协议发送一个网页请求：【‌应用层‌：HTTP请求被封装成应用层PDU（在这个例子中是一个HTTP请求消息）。传输层‌：应用层的PDU被封装进TCP段中（或使用UDP如果不需要可靠传输）。网络层‌：TCP段被进一步封装进IP数据报中。‌链路层‌：IP数据报被封装进帧中，并通过物理媒体发送。】

DIADesigner 是‌台达公司推出的工业自动化编程软件‌，集成在 DIAStudio 平台中，主要用于 PLC 程序编写、参数设定和设备调试 。

TIA博途（TIA Portal）是西门子工业自动化集团于2010年11月23日发布的全集成自动化软件平台。该平台采用统一的工程组态和软件项目环境，适用于自动化系统的开发与调试。用户能够通过该平台进行自动化系统的开发和调试。与传统方法相比，该平台有助于降低集成不同软件包所需的时间与成本 \[4]。该软件平台具备一致的用户界面、基于SIMATIC WinCC Unified的可视化功能以及本地、订阅或云端等多种部署模式。

‌SCADA‌是‌数据采集与监视控制系统‌的缩写，全称是‌Supervisory Control And Data Acquisition‌，中文读音类似"‌吸卡达‌"，也可以直接按字母念 S-C-A-D-A。它本质上是一套基于计算机技术的工业自动化控制系统，主要用来对分散在各地的工业设备进行远程监控、数据采集和自动控制，相当于工业现场的“千里眼”和“顺风耳”。‌

SCADA 系统通常由三个主要部分配合工作，就像人的大脑、神经和手脚一样协同运作 ：‌‌【上位机（监控中心）‌：这是系统的“大脑”，包括数据服务器和人机界面（HMI），负责集中显示数据、发出控制指令，让操作人员能直观看到现场情况 。‌下位机（现场设备）‌：这是系统的“手脚”，包括远程终端单元（RTU）和可编程逻辑控制器（PLC），安装在设备旁边，负责直接连接传感器采集数据并执行开关动作 。‌通信网络‌：这是系统的“神经”，通过有线或无线网络把上位机和下位机连接起来，保证数据能实时传输 。‌】【这套系统核心能干四件事，行话叫“四遥”，能把复杂的人工操作变成自动化管理 ：‌数据采集与监控、‌远程控制与调节‌、报警与事件管理‌、‌与上层系统配合（将采集的数据传给MES）】

OPC UA 全称 OPC Unified Architecture，中文叫 OPC 统一架构，是 OPC 基金会 2008 年发布的工业通信标准，用于替代传统基于 Windows COM/DCOM 的 OPC 协议 。是新一代工业自动化通用标准通信协议‌，跨平台、高安全、标准化极强，是工业 4.0 和智能制造的核心通信标准 。‌‌【核心作用‌：让不同厂家的工业设备（如 PLC、传感器、工控机）能够互相交换数据，实现从车间设备到 MES、ERP 系统甚至云端的无缝通信 。技术基础‌：基于 TCP/IP 协议传输，支持二进制和 XML 两种数据格式，不再依赖 Windows 系统，可运行在 Linux、嵌入式设备、云平台等多种平台上 。‌‌ 】

OLE = Object Linking and Embedding（对象链接与嵌入）‌，是微软1990年代用于实现应用程序间对象共享的底层技术，OPC 标准最初基于此构建（现已被 OPC UA 取代）。‌

OPC【基本功能：OPC 全称是 OLE for Process Control（用于过程控制的 OLE），是‌工业自动化领域的通信协议标准‌，用于解决不同厂商设备之间的数据交换问题 。工作原理‌： 采用客户/服务器架构，定义统一接口，让上位机软件（如监控系统）能直接读取下位机设备（如 PLC、仪表）的数据，无需为每种设备单独开发驱动 。技术演变‌：1996 年首次发布，早期基于 Windows 的 DCOM 技术，后因安全和配置问题，2010 年后升级为平台无关的‌OPC UA 架构‌，支持跨平台和安全通信 。】

RS-232标准接口（又称EIA RS-232）是常用的串行通信接口标准之一，它是由美国电子工业协会(Electronic Industry Association，EIA)联合贝尔系统公司、调制解调器厂家及计算机终端生产厂家于1970年共同制定，其全名是“数据终端设备( DTE)和数据通信设备(DCE)之间串行二进制数据交换接口技术标准”。

PLC通道（Process Channel）是指可编程逻辑控制器（PLC）与外部现场设备（如传感器、执行器）之间进行信号传输和转换的物理及逻辑路径。它是连接计算机控制系统与生产过程的桥梁，负责双向信息的传递。

MQTT：消息队列遥测传输（Message Queuing Telemetry Transport）;MQTT 采用客户端 - 代理（Client-Broker）架构，通过消息代理服务器实现消息的路由与分发。

MQTT 与 HTTP 在设计目标和应用场景上有显著差异，主要体现在通信模式和资源消耗上 ：‌‌1.‌通信模式‌：MQTT 基于发布/订阅模型，支持一对多消息分发；HTTP 基于请求/响应模型，通常为点对点通信。2.连接方式‌：MQTT 维持长连接，减少频繁建立连接的开销，适合实时数据推送；HTTP 通常为短连接（虽支持持久连接但机制不同），适合网页浏览等场景。3.报文开销‌：MQTT 报文头极小（2 字节），网络流量低；HTTP 报文头较大，包含较多元数据，带宽占用高。4.‌适用场景‌：MQTT 适用于物联网设备状态上报、即时消息推送等低频小数据量场景；HTTP 适用于 API 调用、大文件传输及 Web 资源访问 。‌‌

MQTT 凭借低功耗和高可靠性，已成为物联网领域的事实标准，广泛应用于以下场景：智能家居、工业互联网、车联网、远程医疗、移动应用。

OEM原始设备制造商，OEM是英文Original Equipment Manufacturer的缩写，也称为定点生产，俗称代工（生产），基本含义为品牌拥有者不直接生产产品，而是利用自己掌握的关键的核心技术负责设计和开发新产品，控制销售渠道。

ROI 投资回报率（return on investment）是指通过投资而应返回的价值，即企业从一项投资活动中得到的经济回报。

物联网（英文：Internet of Things，缩写：IoT）起源于传媒领域，是信息科技产业的第三次革命。物联网是指通过信息传感设备，按约定的协议，将任何物体与网络相连接，物体通过信息传播媒介进行信息交换和通信，以实现智能化识别、定位、跟踪、监管等功能。

可编程逻辑控制器（Programmable Logic Controller，PLC），是以微处理器为核心，综合计算机技术、自动控制技术和通信技术发展起来的一种通用工业自动控制装置 \[13]，采用可编程存储器作为内部指令记忆装置，具有逻辑、排序、定时、计数及算术运算等功能。 \[13]

Modbus是一种串行通信协议，是Modicon公司（现在的施耐德电气Schneider Electric）于1979年为使用可编程逻辑控制器（PLC）通信而发表。Modbus已经成为工业领域通信协议的业界标准（De facto），并且现在是工业电子设备之间常用的连接方式。 \[1]Modbus比其他通信协议使用的更广泛的主要原因有： \[2]【公开发表并且无版权要求2.易于部署和维护3.对供应商来说，修改移动本地的比特或字节没有很多限制】

具身智能机器人（Embodied Intelligent Robot），常被简称为“具身机器人”，是一种拥有物理实体的人工智能系统，它通过“身体”上的多模态传感器与环境交互，并基于感知信息进行自主决策与执行，形成“感知-决策-执行”的闭环，从而在真实物理世界中完成任务并持续学习进化 。‌

具身智能机器人的核心在于“具身性”与“交互性”，它标志着人工智能从纯粹的软件和数字世界，走向了能与物理现实深度融合的新阶段 。‌
